# 各层数据调用

不同角色和工具从不同层取数，**各取所需、互不干扰**。

## 1. 角色 × 层级对照表

| 角色 | 主要使用层级 | 用途 |
| :--- | :--- | :--- |
| 数据工程师 | Bronze（排查）、Silver（清洗建模） | 排查数据问题、建设清洗/建模链路 |
| 数据科学家 | Silver | 干净的明细数据用于特征工程和模型训练 |
| 数据分析师 / BI 工具 | Gold / Application | 聚合表用于报表和分析 |
| 外部系统 | Application / Gold | 通过 API 或数据同步任务取数 |

## 2. 各角色的取数方式

- **数据工程师**：在 **Bronze 层**排查数据问题；在 **Silver 层**进行清洗建模。
- **数据科学家**：从 **Silver 层**获取干净的历史明细数据，用于特征工程和模型训练。
- **数据分析师/BI 工具**：连接 **Gold 层**或 **Application 层**的聚合表进行报表制作和分析。
- **外部系统**：通过 API 或数据同步任务，从 **Application 层**或 **Gold 层**获取数据。

## 3. 权限建议

- **Bronze**：只读给数据工程师，一般不开放给下游。
- **Silver**：开放给数据科学与工程团队。
- **Gold / Application**：开放给 BI 与业务方。

> 在阿里云里，这种"按层授权"通过 **DLF 的权限管理** 或 **OSS 的 Bucket Policy** 实现，详见《阿里云 DataLake 说明与使用》系列。
