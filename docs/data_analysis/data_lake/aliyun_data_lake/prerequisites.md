# 入湖前置准备

正式入湖前，先完成三件准备工作：**开通服务、网络打通、账号授权**。

## 1. 开通服务（并保证同地域）

1. 登录阿里云控制台，开通 **OSS、DLF、DTS**（EMR 后续分层再开）。
2. **关键**：确保 **OSS、DLF、RDS SQL Server（或自建 SQL Server）在同一地域（Region）**。同一地域才能走内网高速连通，且**免收跨地域数据传输费**。

## 2. 网络配置

把同步/计算服务的网段加入源库白名单：

- 将 **DTS 服务的 IP 地址段** 加入 RDS SQL Server 白名单。
- 将 **DLF/EMR 的 VPC** 加入白名单（若走 VPC 内网）。

> 控制台路径：RDS 实例 → 数据安全性 → 白名单设置 → 添加。

## 3. 账号授权

1. **DLF 服务关联角色授权**：首次使用 DLF 时按提示授权，允许 DLF 读取 OSS、访问 RDS。
2. **RAM 用户授权**：给操作用户授予 `AliyunDLFFullAccess` 权限。
3. 确认 DTS 具备访问源库（SQL Server）和目标（OSS）的权限。

> 控制台路径：RAM 访问控制 → 用户 → 授权。

## 4. 检查清单

- [ ] OSS / DLF / DTS 已开通
- [ ] 所有服务在同一地域
- [ ] 源库白名单已添加 DTS 网段
- [ ] DLF 服务关联角色已授权
- [ ] RAM 用户有 `AliyunDLFFullAccess`
